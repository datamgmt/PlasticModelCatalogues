# Plastic Model Catalogues

## The Digital Catalogue

Many collectors annd re-sellers will find having an electronic list of plastic models by vendor extremely useful including:

* Research into available and historical models
* Cataloging a collection
* Providing data for e-commerce solutions

The data found in thisn repository is information I have collected. It may not be up to date, etc. but is a useful starting point
